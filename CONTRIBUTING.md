# Contribuer à MaxPS4

Merci de votre intérêt pour MaxPS4.

MaxPS4 est un projet communautaire visant à expérimenter un frontend iOS autour d'un port de shadPS4.

## Comment contribuer

Vous pouvez contribuer en :

- signalant des bugs via les Issues GitHub ;
- proposant des corrections et améliorations via Pull Requests ;
- testant les builds iOS et en partageant des logs reproductibles ;
- améliorant l'interface, la documentation et la compatibilité iOS ;
- contribuant au travail d'intégration du core shadPS4.

## Avant une Pull Request

1. Décrivez clairement le problème ou l'amélioration.
2. Gardez les modifications ciblées et documentées.
3. Vérifiez que le projet compile autant que possible.
4. N'incluez aucun jeu PS4, PKG commercial, clé, firmware, contenu protégé ou autre matériel dont vous ne possédez pas les droits de redistribution.
5. Respectez les licences des projets tiers utilisés par MaxPS4.

## Crédits et projets tiers

MaxPS4 utilise et expérimente autour du projet open source shadPS4 :
https://github.com/shadps4-emu/shadPS4

shadPS4 et ses contributeurs restent les auteurs de leur projet et de leur code. MaxPS4 n'est pas un projet officiel de Sony Interactive Entertainment et n'est pas affilié à Sony ou PlayStation.
