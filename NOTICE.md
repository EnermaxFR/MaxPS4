# MaxPS4 — Notices and attribution

MaxPS4 is an iOS-oriented project that integrates and modifies source code from the shadPS4 project in order to experiment with a PlayStation 4 emulator engine on iOS.

## shadPS4

Upstream project: https://github.com/shadps4-emu/shadPS4

The MaxPS4 iOS build currently uses shadPS4 commit:

`b3452cf6a9bd0969771fcfbf919c359368473d1b`

The build applies iOS-specific modifications to upstream shadPS4 sources. Those modifications are described and reproducible from the build scripts and GitHub Actions workflow contained in this repository.
